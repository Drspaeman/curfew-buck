# Hunter Sub (play build)

Play in your browser: **https://drspaeman.github.io/hunter-sub-play/**

A comedy stealth game. Bow-hunt deer in your ex-wife's subdivision before sunrise, sell the venison to a sketchy guy in a van, and save Grandpa's woods from the HOA. Works on desktop (keyboard + mouse or gamepad) and phones (touch controls).

This repo only holds the playable files. They're published automatically from the main project.
